# Vibe Coding e Inteligência Artificial na Criação de Jogos Didáticos para o Ensino de Matemática no Ensino Médio

Plataforma educacional estática criada para o repositório **mathvibe**, voltada ao Ensino Médio brasileiro. O projeto apresenta jogos didáticos, sequências didáticas, explicações teóricas, gamificação, ranking local e organização pedagógica alinhada à BNCC.

## Objetivo

Servir como produto educacional de TCC, demonstrando como vibe coding e inteligência artificial podem apoiar a criação de recursos digitais para o ensino de Matemática.

## Tecnologias

- HTML5
- CSS3 moderno
- JavaScript puro
- LocalStorage para progresso, conquistas e ranking
- Sem backend
- Compatível com GitHub Pages

## Como executar localmente

Abra o arquivo `index.html` no navegador ou use uma extensão de servidor local, como Live Server.

## Como publicar no GitHub Pages

1. Envie todos os arquivos para o repositório `mathvibe`.
2. Acesse as configurações do repositório no GitHub.
3. Entre em **Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch principal e a pasta raiz.
6. Salve e aguarde a publicação.

## Observações pedagógicas

As sequências didáticas apresentam objetivos, habilidades da BNCC, metodologia, recursos, etapas, avaliação e atividades complementares. Os jogos foram planejados para apoiar metodologias ativas, aprendizagem por desafios e uso responsável de tecnologias digitais na educação.
